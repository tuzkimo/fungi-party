# 菌子派对（FungiParty）

一朵蘑菇在森林里散步，走进教室上「偷吃课」，赢点蘑菇币去摊位换一顶新帽子。

## 你会玩到什么

**森林**
一片会走动的圆润森林：树、石头、白天到黑夜的光。没有任务、没有引导，先随便走走。

**上课偷吃大赛**
森林深处的校门通向一间教室。你坐在四张课桌中的一张，另外三个是同学，前面站着老师。

- 老师看黑板的时候，按住屏幕吃；他转过头来看你，马上松手装样子
- 被看到超过一下就罚站 3 秒，一局里被抓 3 次就出局
- 先吃满 20 口的人赢；时间到了就按口数结算
- 三个同学有各自的性格：胆小的先松手，胆大的总想多贪一口，偶尔就有人被拎起来罚站

**课堂之外的摊位**
一局结束，吃到的口数、赢没赢，都会换成蘑菇币。攒够了去森林里的小摊，摊主卖一顶蓝莓帽。买下之后你的蘑菇会立刻变蓝，教室里坐着的那个也一样；想换回原来的红帽子，摊位上点一下就行。

## 操作

单指。左下角摇杆走路，右下角按钮跳；进教室后只需要按住与松手。
在电脑上试玩时，用 WASD 走路、空格跳、按住空格吃东西。
