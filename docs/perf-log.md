## v3 森林赛跑（2026-10-18）

- 真机：Redmi 24122RKC7C，赛跑场景 120 FPS（vsync 顶住），DRAW 158~203（阴影 pass 让每块障碍的 draw call 翻倍），VRAM 69MB。TRI 没取到：DebugHUD 只在 `main.tscn` 里，赛跑场景没有；要测就把那 14 行挂上去。
- 障碍组 10~11 组/局（间距 16.5~18m）：为了满足「动物横穿处离障碍组 ≥ 8m」，最小间距从计划的 12m 提到 16.5m，否则禁入区在 12~18m 间距下互相重叠，没有合法横穿点。
- 人机 40 局平均（`RaceRacer` 纯模型跑，不含节点）：稳中型 36.9s / 撞 0.25 次，贴边型 46.3s / 撞 11.4 次，冲动型 34.7s / 撞 0.3 次；全部完赛，无卡死。
- 玩家侧自动驾驶脚本（会瞄准缝、绕松果、CD 好就冲刺，不会跳）一局 36~45s、撞 0~8 次，名次多为第 3。人手玩会跳、会预判动物，理论上靠冲刺能进 34s，与冲动型互有胜负——「三次内能拿一次第一」还需要一次真人试玩确认。
- 真机三局走查**未做**：MIUI 拒绝 `adb shell input`（INJECT_EVENTS permission），触摸只能人肉验。已做的真机验证是：清空 logcat 后从 forest 启动、以及临时把主场景换成 `race.tscn` 跑一局（无输入，玩家原地不动），两边日志都只有赛道布局一行、无 ERROR/警告，截图见 `shots/v3-race.png`。
- 场景往返（森林 → 赛跑 → 森林 → 赛跑 → 森林）用无头脚本连切，无 ERROR、无「previously freed instance」，`再来一局`/`回森林` 两个按钮的信号路径都通。
