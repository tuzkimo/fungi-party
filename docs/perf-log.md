# 真机性能记录

| 日期 | 机型 | 场景 | FPS | DRAW | TRI（含阴影 pass） |
|---|---|---|---|---|---|
| 2026-10-17 | Redmi 24122RKC7C（Adreno 830, Vulkan 1.3） | 空场景 + FPS 标签 | 120 | 1 | 32 |
| 2026-10-17 | 同上 | 蘑菇角色 + 相机 + 地板 | 120 | 45 | 32.3k |
| 2026-10-17 | 同上 | 完整森林（240 树 + 40 石 + 地形）+ 昼夜 | 120 | 35 | 299.6k |

- 屏幕刷新率 120Hz，FPS 被 vsync 顶住，不能直接读出余量；要测余量需要临时关 vsync 或加压力测试。
- 三角面计数包含阴影 pass 与 MultiMesh 实例，spec 里写的「可见 <60k」是单 pass 估算，实际以真机帧率为准。
- 以上数据全部来自一台旗舰机（Adreno 830）且被 120Hz vsync 顶住，**未在中端/低端机验证**。spec 的目标是中端 60 / 低端 30，这条尚未被证实。
- 首帧卡顿未测量：地形网格 + 240 个树干碰撞体 + 3 个 MultiMesh 全在 `ForestGen._ready()` 的第一帧生成。
