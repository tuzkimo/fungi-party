# 森林扔粑粑 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让两个联机玩家在森林里（不换场景）互相扔粑粑：先被打中三次的输、输的给赢的 5 蘑菇币；弹药得从地上推粪球的屎壳郎身上抢。

**Architecture:** 服务器把 `poop` 当成第六种 `NetRoom.KINDS`，只跑一个 RefCounted 的 `PoopRound`（屎壳郎、抢粪、粑粑直线飞行、三次命中、结算）；玩家位置沿用现成的 `MOVE`。客户端不换场景：森林里常驻一个 `PoopGame` 按 `SESSION` 快照驱动准星和 HUD，一个 `PoopField` 按快照画出屎壳郎和飞行的粑粑，`game/ui/poop_panel.gd` 只画不判。

**Tech Stack:** Godot 4.7.2 / GDScript / ENet（`NetProtocol` 自建信封）/ 无头测试 `bash scripts/test.sh`。

**Spec:** `docs/superpowers/specs/2026-11-14-poop-duel-design.md`

## Global Constraints

- 服务器上只跑 RefCounted（绝不实例化 3D 场景）；位置、输入、昵称全是信任边界，类型不对一律拒，不当 0 处理。
- 数字全部进 `game/config.gd` 的 `const`：`POOP_SECONDS 180.0`、`POOP_HITS 3`、`POOP_STAKE 5`、`POOP_AMMO_MAX 3`、`POOP_THROW_SPEED 14.0`、`POOP_RANGE 30.0`、`POOP_HIT_RADIUS 0.6`、`POOP_CHEST 0.7`、`POOP_BEETLES 5`、`POOP_SPAWN_RADIUS 25.0`、`POOP_BALL_REFILL 6.0`、`POOP_PICK_RANGE 1.5`、`POOP_BEETLE_SPEED 0.7`、`POOP_BEETLE_WANDER 3.0`、`POOP_BALL_AHEAD 0.6`。
- **粑粑直线飞、不下坠**：屏幕正中就是落点，不准引入重力（有重力准星就在说谎）。
- 命中、抢粪、弹药、胜负 **全在服务器**；客户端只说「我按了扔，方向是这个」。
- `NetProtocol.VERSION` 10 → 11，客户端和服务端一起发版。
- 动态拼的中文文案只用 ASCII 标点（真机系统字体没有全角括号）。
- 非平凡逻辑先写测试，能抽纯函数的抽 `static func`。
- 提交信息用中文。

## Review Focus

- **局中有人掉线**：剩下那台不能挂着等满 180 秒，必须立刻收局且两边都不动钱（`NetLobby.drop`）。
- **一个 MOVE 都没报过**（刚成局就卡了 / 邀请完立刻切后台）：抢不到粪、扔不出去、也打不中人，而不是崩在 `INF` 坐标上或「从原点扔出去打中自己」。
- **钱包**：输家不足 5 币时只扣到 0，赢家只拿实际扣到的；认输（`leave_room`）照付，掉线不付。
- **180 秒 / `NET_ROOM_MAX_SECONDS 300`**：两条到点路径都必须给出确定结果（赢家或平局），且不能把「同时一间房」卡住。
- **2P 与包大小**：一个账号两份位置，被砸、抢粪都按账号算（不能一个账号两条命）；5 只屎壳郎 + 若干发粑粑在 20 Hz 下不能超过 `NetProtocol.MAX_PACKET`，否则服务器静默丢包，看起来像「服务器不广播了」。

**Interfaces:**
- Produces: `class_name PoopRound extends RefCounted`
  - 字段：`left: float`（默认 `Config.POOP_SECONDS`）、`over: bool`、`winner: int`（默认 -1）、`humans: int`、`hits: Dictionary`（座位 → 次数）、`ammo: Dictionary`（座位 → 发数）、`beetles: Array[Dictionary]`、`shots: Array[Dictionary]`
  - `_init(humans_value := 2, seed_value := 0) -> void`：把 `hits` / `ammo` 的 0..humans-1 号座初始化成 0，`_rng` 用 `seed_value` 播种
  - `anchor(center: Vector3) -> void`：只在第一次调用时撒 `Config.POOP_BEETLES` 只屎壳郎（`center` 周围 `Config.POOP_SPAWN_RADIUS` 内），再调用什么也不做
  - `feed(seat: int, slot: int, spot: Vector3) -> void`：和 `HideRound.feed` 同形（slot 只收 0/1，非有限数不采信）
  - `throw_poop(seat: int, dir: Vector3) -> bool`
  - `tick(delta: float) -> void`
  - `coins_for(seat: int) -> int`、`forfeit(seat: int) -> bool`、`snapshot() -> Dictionary`
  - 静态：`aim_ok(dir: Vector3) -> bool`、`segment_hit(from: Vector3, to: Vector3, chest: Vector3, radius: float) -> bool`、`ball_at(beetle: Dictionary) -> Vector2`、`loser_by_hits(hits: Array, humans: int) -> int`（挨得最多的座位号，平局 -1）
- 屎壳郎字典的形状（客户端和测试都按这个读）：`{"x": float, "z": float, "yaw": float, "ball": bool, "timer": float, "refill": float}`
- 粑粑字典：`{"owner": int, "x": float, "y": float, "z": float, "dx": float, "dy": float, "dz": float, "left": float}`
- `snapshot()` 返回 `{"left", "hits", "ammo", "beetles", "shots", "over", "winner"}`，其中 `hits` / `ammo` 是长度 `Config.SEAT_COUNT` 的数组（没坐人的座位是 0）。
- 粪球在屎壳郎**身前**（节点自己的 -Z）：`ball_at` 返回 `Vector2(x - sin(yaw) * AHEAD, z - cos(yaw) * AHEAD)`。yaw 0 时球在 z 更小的那一侧。

**实现要点（签名和测试决定了不出来的那几处）：**

- `tick` 顺序：`over` 直接返回 → 扣 `left`（到 0 就按 `loser_by_hits` 判，平局 `winner = -1`，`over = true`，返回）→ 推屎壳郎 → 补粪球 → 抢粪 → 飞粑粑并判命中 → 三次命中收局。
- 推屎壳郎：`timer -= delta`，到 0 就把 `timer` 重设为 `POOP_BEETLE_WANDER`、`yaw` 取 `_rng.randf() * TAU`；然后按 `(sin yaw, cos yaw) * POOP_BEETLE_SPEED * delta` 走一步。走出 `POOP_SPAWN_RADIUS` 就把 `yaw` 指向 `_center`（`atan2(center.x - x, center.z - z)`），弹药得留在战场附近。
- 补粪球：`ball == false` 时 `refill -= delta`，到 0 就 `ball = true`。被抢时把 `refill` 设成 `POOP_BALL_REFILL`。
- 抢粪：座位外层（0 到 humans-1 升序，座位小的先拿），屎壳郎内层；座位任一 slot 与 `ball_at` 的**水平**距离 ≤ `POOP_PICK_RANGE` 且 `ball` 为真且槽没满 → `ammo[seat] += 1`、`ball = false`、`refill = POOP_BALL_REFILL`，然后看下一只。
- 出手点：这个座位 **slot 0** 的坐标（没报过就用 slot 1，都没有就扔不出去），`+ Vector3(0, POOP_CHEST, 0)`。
- 飞粑粑：每 tick 从旧坐标往新坐标（`speed * delta`）扫一段，对**除自己以外**每个座位的每个 slot 的胸口 `pos + Vector3(0, POOP_CHEST, 0)` 做 `segment_hit`；命中就 `hits[那个座位] += 1` 并删掉这一发。`left` 到 0 也删。倒序遍历删（`range(size - 1, -1, -1)`）。
- 命中谁：按**座位（账号）**记，不按 slot。

```gdscript
extends TestBase

## 扔粑粑的服务器规则：抢粪、直线飞行、三次命中、超时判。

const SEED := 7


func _r() -> PoopRound:
	return PoopRound.new(2, SEED)


## 屎壳郎摆成固定位置（不依赖随机撒点）
func _place(r: PoopRound, spots: Array) -> void:
	r.beetles.clear()
	for spot in spots:
		r.beetles.append({"x": spot.x, "z": spot.z, "yaw": 0.0, "ball": true, "timer": 999.0, "refill": 0.0})


## 让人站到第 beetle 只的粪球上（另一个座位扔到很远，免得顺手抢到别的球）
func _stand_on_ball(r: PoopRound, seat: int, beetle: int) -> void:
	var ball := PoopRound.ball_at(r.beetles[beetle])
	r.feed(seat, 0, Vector3(ball.x, 0.0, ball.y))
	r.feed(1 - seat, 0, Vector3(500.0, 0.0, 500.0))
	r.tick(0.0)


func test_fresh_round_is_empty() -> void:
	var r := _r()
	check_eq(r.left, Config.POOP_SECONDS, "开局满时长")
	check_eq(int(r.ammo.get(0, 0)), 0, "0 号座没弹药")
	check_eq(int(r.hits.get(1, 0)), 0, "1 号座没挨打")
	check_eq(r.beetles.size(), 0, "没人报位置之前不撒屎壳郎")
	check_eq(r.over, false, "没结束")


func test_anchor_spawns_beetles_once() -> void:
	var r := _r()
	r.anchor(Vector3(10.0, 0.0, -4.0))
	check_eq(r.beetles.size(), Config.POOP_BEETLES, "撒 %d 只" % Config.POOP_BEETLES)
	for b in r.beetles:
		var at := Vector2(float(b["x"]), float(b["z"]))
		check(at.distance_to(Vector2(10.0, -4.0)) <= Config.POOP_SPAWN_RADIUS + 0.001, "撒在中点附近")
		check_eq(b["ball"], true, "每只都推着一个球")
	r.anchor(Vector3(-50.0, 0.0, 0.0))
	check_eq(r.beetles.size(), Config.POOP_BEETLES, "锚点只认第一次，再调不多撒一层")


func test_ball_sits_in_front_of_the_beetle() -> void:
	var front := Vector2(3.0, 4.0 - Config.POOP_BALL_AHEAD)
	check(PoopRound.ball_at({"x": 3.0, "z": 4.0, "yaw": 0.0}).is_equal_approx(front), "朝 -Z 推着")
	var back := Vector2(3.0, 4.0 + Config.POOP_BALL_AHEAD)
	check(PoopRound.ball_at({"x": 3.0, "z": 4.0, "yaw": PI}).is_equal_approx(back), "转半圈球在另一头")


func test_walking_onto_a_ball_picks_it_up() -> void:
	var r := _r()
	_place(r, [Vector3(0.0, 0.0, 0.0)])
	r.feed(0, 0, Vector3(0.0, 0.0, 3.0 - Config.POOP_BALL_AHEAD))
	r.tick(0.0)
	check_eq(int(r.ammo.get(0, 0)), 0, "离 3 米抢不到")
	check_eq(r.beetles[0]["ball"], true, "球还在")
	_stand_on_ball(r, 0, 0)
	check_eq(int(r.ammo.get(0, 0)), 1, "走到球上自动拿到一个")
	check_eq(r.beetles[0]["ball"], false, "球被拿走了")


func test_full_slots_refuse_more() -> void:
	var r := _r()
	_place(r, [Vector3(0, 0, 0), Vector3(50, 0, 0), Vector3(100, 0, 0), Vector3(150, 0, 0)])
	for i in Config.POOP_AMMO_MAX:
		_stand_on_ball(r, 0, i)
	check_eq(int(r.ammo.get(0, 0)), Config.POOP_AMMO_MAX, "满槽 %d 发" % Config.POOP_AMMO_MAX)
	_stand_on_ball(r, 0, 3)
	check_eq(int(r.ammo.get(0, 0)), Config.POOP_AMMO_MAX, "满了不再抢")
	check_eq(r.beetles[3]["ball"], true, "球留在原地，谁缺谁拿")


func test_ball_grows_back_after_a_while() -> void:
	var r := _r()
	_place(r, [Vector3(0, 0, 0)])
	_stand_on_ball(r, 0, 0)
	r.feed(0, 0, Vector3(500.0, 0.0, 500.0))
	r.tick(Config.POOP_BALL_REFILL - 0.2)
	check_eq(r.beetles[0]["ball"], false, "还没补上")
	r.tick(0.4)
	check_eq(r.beetles[0]["ball"], true, "%s 秒后屎壳郎又推一个出来" % Config.POOP_BALL_REFILL)


func test_throw_needs_ammo_and_a_direction() -> void:
	var r := _r()
	_place(r, [Vector3(0, 0, 0)])
	r.feed(0, 0, Vector3.ZERO)
	check_eq(r.throw_poop(0, Vector3.FORWARD), false, "没弹药扔不出去")
	_stand_on_ball(r, 0, 0)
	check_eq(r.throw_poop(0, Vector3.ZERO), false, "零向量不收")
	check_eq(r.throw_poop(0, Vector3(INF, 0.0, 0.0)), false, "非有限数不收")
	check_eq(r.throw_poop(0, Vector3.FORWARD), true, "有弹药有方向就飞出去")
	check_eq(int(r.ammo[0]), 0, "扔一发少一个")
	check_eq(r.shots.size(), 1, "天上有一发")


func test_throw_without_positions_fails() -> void:
	var r := _r()
	_place(r, [Vector3(0, 0, 0)])
	r.ammo[0] = 1
	check_eq(r.throw_poop(0, Vector3.FORWARD), false, "没报过位置不知道从哪扔")


func test_straight_shot_hits_the_chest() -> void:
	var r := _r()
	_place(r, [Vector3(0, 0, 0)])
	_stand_on_ball(r, 0, 0)
	r.feed(0, 0, Vector3.ZERO)
	r.feed(1, 0, Vector3(0.0, 0.0, -8.0))
	r.throw_poop(0, Vector3.FORWARD)
	r.tick(0.2)
	r.tick(0.2)
	check_eq(int(r.hits[1]), 0, "两步才到 -5.6 米，还没打中")
	r.tick(0.2)
	check_eq(int(r.hits[1]), 1, "这一步跨过 -8 米，线段扫到胸口（点判会漏）")
	check_eq(r.shots.size(), 0, "打中就消失")


func test_shot_misses_when_aimed_aside() -> void:
	var r := _r()
	_place(r, [Vector3(0, 0, 0)])
	_stand_on_ball(r, 0, 0)
	r.feed(0, 0, Vector3.ZERO)
	r.feed(1, 0, Vector3(0.0, 0.0, -8.0))

func test_two_p_slots_both_count() -> void:
```
