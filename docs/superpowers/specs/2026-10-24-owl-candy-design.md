# 猫头鹰喂食（第四款小游戏）设计文档

日期：2026-10-24
状态：已确认方案，待实现
父文档：`docs/superpowers/specs/2026-10-17-fungi-party-design.md`

## 1. 这是什么

森林里多了一棵歪脖子大树，猫头鹰老师蹲在树杈上往下扔东西：糖果，和屎。

四个菌子并排坐在树下一排，各自头上一根投喂线，互不干扰。**长按屏幕张嘴，松手闭嘴**。东西落到嘴边的瞬间嘴张着就算吃到：糖加 1 分，屎当场出局，本关剩下的时间只能看着别人吃（2.5 倍速快进）。嘴闭着就什么也接不到：糖漏了就是丢分，屎安全落地。

三关，一关比一关快。三关打完，四个菌子比总分排名，按名次发蘑菇币。

和前三款的区别：偷吃比的是「忍住」，赛跑比的是「跑和躲」，炸弹比的是「敢抱多久」，这一款比的是**认和缩手**——认出掉下来的是屎，然后赶在它到嘴边之前把手松开。

## 2. 目标 / 非目标 / 反目标

**目标**
- 一句话讲清规则：长按张嘴，看到屎松手。不需要教学关。
- 反应窗口从第 1 关的 1.1 秒收到第 3 关的 0.7 秒，第三关要真的绷起来。
- 吃到屎的瞬间玩家心里得是「我看到它了，手慢了半拍」，不是「这什么啊」。
- 全程 105 秒（3 秒倒数 + 30 + 35 + 40 秒），比炸弹（30~40 秒）长，比偷吃（90 秒）长一点，是三款里最长的一局，但每关都有结算式停顿，节奏不断。

**非目标（这一版不做）**
- 四个玩家抢同一个落点（讨论过，要加移动/碰撞，是另一个游戏）。
- 饥饿条、必须吃够 N 颗才算过关（改成四人同场后由分数竞争天然兜住：不张嘴就是 0 分）。
- 道具、连击、糖果分大小、特殊糖果。
- 出局后复活、第二条命。
- 存档记最高关数（每局都从第 1 关开始）。

**反目标（做成了算失败）**
- 玩家分不清糖和屎——那就变成摇骰子。
- 出局后干等 25 秒无事可做（已定：2.5 倍速快进）。
- 感觉是「NPC 在演我」：NPC 分数必须能解释——贪的那个分高但常出局，胆小的稳但分低。
- 一关 40 秒里出现两个 NPC 吃屎，屏幕上同时两条信息抢注意力。

## 3. 约束

- Godot 4.7.2、Mobile 渲染器、横屏 1280×720。材质只用 `StandardMaterial3D`，不写 shader。
- 自包含单场景 `game/minigame/owl.tscn`，节点间直接 `$` 引用；森林侧跨场景引用（`owl_tree`）每帧惰性 `get_first_node_in_group`。
- 可调数字全进 `game/config.gd`。扣体力只在本小游戏 `_ready` 一处，走 `Save.spend_stamina()`。
- 回合规则写成纯模型 `OwlRound`（`RefCounted`，不碰节点），无头测试直接跑。
- 大件几何用 MultiMesh；这一款几何量很小（一棵树 + 四个蘑菇 + 8 个小物件），不强行 MultiMesh。
- 提交信息用中文。

## 4. 规则

### 4.1 判定

每个座位一条独立投喂线，同一时刻线上最多一样东西。

东西抵达嘴边的**那一刻**只看一个布尔：嘴张着吗？

| 掉下来的 | 嘴张着 | 嘴闭着 |
|---|---|---|
| 糖果 | +1 分 | 漏掉，不加分 |
| 屎 | 出局（本关剩余时间作废） | 安全 |

判定是纯时间比较，不做物理碰撞。这样整个规则能写成纯函数，在无头测试里跑完整局。

### 4.2 三关

| | 第 1 关 | 第 2 关 | 第 3 关 |
|---|---|---|---|
| 时长 | 30s | 35s | 40s |
| 投喂间隔（每人独立随机） | 1.6–2.4s | 1.3–1.9s | 1.0–1.5s |
| 下落时长（树杈到嘴边） | 1.1s | 0.9s | 0.7s |
| 屎比例 | 25% | 33% | 40% |

**下落时长是主难度旋钮**：糖和屎在下落途中就能看出颜色形状，玩家是「认出来是屎再松手」，可用的反应时间就是下落那几百毫秒。投喂间隔只决定密度，屎比例决定诱惑有多少。

一关里玩家出局后，剩余时间按 **2.5 倍速**跑完（NPC 分数照实累加，不做补算），玩家观看。三关之间 1.6 秒「第 N 关」停顿，期间不吃、不计分。

### 4.3 计分与结算

- 一颗糖 1 分，跨关累加。HUD 顶上一行：`第 2/3 关 · 剩 18 秒` + `你 8 · 稳 7 · 贪 9 · 胆小 5`。
- 三关打完按总分排名，同分按座位序（玩家在前，即玩家赢平局）。
- 币只按名次发：70 / 50 / 35 / 20。**不做每颗糖加币**——加币公式一多，玩家就会开始算「吃多少颗回本」，这一款的乐趣不在算账。
- 体力一次扣 30（三关连打，比传炸弹 25 高一档）。

### 4.4 三个 NPC

三个性格，各自的差异只体现在两个数上，由种子决定，可复现：

| 名字 | 糖敢不敢吃 | 屎会不会误吞 | 张嘴的时机 |
|---|---|---|---|
| 稳 | 0.9 | 0.05 | 提前量随机 0.15–0.8 倍下落时长 |
| 贪 | 0.97 | 0.28 | 同上（抢得凶，也最容易吃屎） |
| 胆小 | 0.75 | 0.02 | 提前量 0.35–1.0 倍（张得早，看着更谨慎） |

失手只来自「不敢吃」那两个概率，不再额外写第二套失误逻辑：糖没敢吃就是漏掉，屎没识别出来就是出局。提前量只决定张嘴看起来早还是晚，让四个人不同步。

## 5. 怎么建

只有一个方案，其余都不成立：

- **种子 + 预生成投喂表**（`OwlRound`，和 `RaceField` / `BombRound` / `StealEat` 一致）：每关开始按种子排出四条线的投喂序列（抵达时刻、下落时长、是糖是屎），`tick` 只推进指针。可复现、可无头测试。
- ~~每帧实时随机~~：代码更少，但同一帧数下不可复现，测试只能测「没崩」，项目规定非平凡逻辑先写测试，走不通。
- ~~复用教室的 `NpcSeat` / 炸弹的 `BombSeat`~~：规则完全不同（一个是视线抓现行的概率，一个是持有节奏），复用只会把两套规则搅在一起。

渲染层只读模型状态：`mouths[i].open`、`flying`（距抵达还有多久）、`poop`，不反过来驱动规则。

## 7. 视觉与操作

- **树**：`(x=-8, z=10)` 一棵比普通树大两号的树，树干 + 三团树冠，鸟蹲在 `y≈3.4` 的树杈上。地面画一圈浅色蘑菇环，跟蘑菇圈的石头环一个语言，但不抢戏。
- **猫头鹰**：圆球身体 + 两个大白眼球（黑瞳）+ 橘色三角喙 + 两撮耳羽。扔东西时身体前倾一下。
- **四个座位**：`x = -3.6 / -1.2 / 1.2 / 3.6`，`z = 0`，面朝树。玩家是最左边那个。
- **嘴**：闭嘴时一条深色缝；张嘴时头微微后仰、嘴变宽变高的椭圆，露出粉色口腔。**张嘴幅度要大**，手机小屏上一眼能看出自己现在是张着还是闭着。
- **糖**：粉色球 + 两端黄色小圆柱（糖纸）；**屎**：棕色球 + 顶上一个小尖锥 + 略微不规则。颜色差得远，形状也差得远，双保险。
- **镜头**：`(0, 2.6, 8.5)` 看向 `(0, 1.4, -1)`，四个座位和树杈上的猫头鹰同时在画面里，全程不移动。
- **操作**：`EatInput`（教室偷吃那套，按手指 index 绑定，抬手事件丢失也自愈）+ 桌面 `空格` 等同按住。底部常驻一行提示：`长按屏幕 = 张嘴，松手 = 闭嘴`。

## 8. 留给实现者的判断

- 具体的树/鸟/蘑菇造型怎么摆才好看，按 §7 的颜色和形状自己定。
- 关间停顿 1.6 秒、快进 2.5 倍速、NPC 那六个概率值——先按上面的数收，试玩后调。
- 结算面板里要不要显示「本关出局」标记：显示（玩家需要知道自己的 0 分是漏的还是死的）。
- 音效：这一版不加（现有 `Sfx` 是炸弹专用的滴答/炸响，硬套会怪）。吃到糖的反馈靠蘑菇弹一下 + 分数跳字。
