# 扔粑粑的手感打磨（v9 表现层）设计

## 要解决什么

扔粑粑已经能玩了，但它是全项目最「干」的一局：打中了没有任何反馈，粑粑是一颗平移的小球，
扔的时候人一动不动，也没有声音和音乐。这一轮只做表现层，不改规则、不动服务端、不动胜负和结账。

## 目标 / 非目标 / 反目标

- 目标：被打中的人有动作（晃一下 + 弹一下）、身上留下溅开的色块；扔出去有起手动作和风声；
  飞的粑粑有朝向、翻滚和一条尾巴；这一局有自己的轻快背景音乐和命中的「啪叽」声。
- 非目标：命中硬直、击退、减速（那是改玩法，`2026-11-14` 那份设计里明确不做）；
  地上的粑粑痕迹、屏幕震动、命中飘出的伤害数字；服务端任何改动。
- 反目标：让表现层影响判定（色块、动作、音效全是客户端自说自话）；
  给服务器加「命中点」字段（要重新部署、踢掉所有人，为几块色块不值）；
  把背景音乐铺到整片森林（那是另一个话题，先只做这一局）。

## 硬约束（现状决定的）

- **快照里没有命中事件也没有命中点**：客户端只能看见 `game.hits[]` 这个累计数在涨。所以
  「被打中」的触发条件是「这一拍某个座位的数变大了」，色块只能贴在**被打中那个人身上**，
  贴不到世界里的命中点。
- **全项目没有音频文件**，声音一律运行时合成 PCM（`game/systems/sfx.gd`）。音乐照这个来，
  否则要凭空引进一个二进制资产和它的授权问题。
- 红蘑菇没有手臂（海鲜菇才有四根棍子手脚），`Player._animate` 每帧独占 `_visual.scale` /
  `position.y`。所以起手动作只能是「蓄力后仰 + 前甩」的整棵身体动作，得和 `chew()` 一样
  挂进 `_animate` 里，不能在外面用 tween 抢。
- `RemotePlayer` 的 `_mesh.scale` / `rotation` 没人用，但它的 `bob()` 每帧由 `main` 驱动 ——
  对面那位的晃动用 `bob()` 顺手带出来，不新开 `_process`。
- 一局最多 8 发粑粑在天上（`PoopField.MAX_SHOTS`），人命 3 次，所以特效总节点数有上限（约 60 个），
  不需要对象池。

## 考虑过的做法

| 做法 | 换来什么 | 代价 | 结论 |
| --- | --- | --- | --- |
| A. 命中点由服务器记进快照（`PoopRound` 多一份 `hit_at`），客户端在命中点喷一摊 | 「真·溅开」的位置 | 动服务端规则模型 = 重新部署 + 踢掉在线的人；快照多一份事件要按「一帧只拍一次」的规矩清 | 否（留给以后真要地面痕迹时） |
| B. **客户端看 `hits[]` 涨了就演：色块贴在被打中那个人的帽子上，人晃一下** | 零服务端改动；换个体型也不会飘（按 `cap_radius_at` 算） | 位置是「人身上」而不是「命中点」；网络延迟 50ms 才看到 | **选它** |
| C. 背景音乐只在这一局放，运行时合成 | 一个节点 + 一段循环；不引入音频文件；出问题只影响这一局 | 品质天花板是「轻快电子小调」 | **选它** |
| D. 背景音乐铺满森林 / 进小游戏也放 | 全局一致 | 要一个常驻音频壳，所有场景都归它管；这一轮用不上 | 否（想清楚了再做） |

## 定稿的细节

1. **击中音效**：`Sfx.pcm_splat` —— 低通噪声的「啪叽」+ 一下下扫的闷响，0.28 秒。
   `Sfx` 原来 `_ensure()` 里就 `_fizz.play()`，那是传炸弹的嗤嗤声底噪；改成只有 `set_danger()`
   才起（传炸弹每帧都调，行为不变），扔粑粑这一局才能借用 `Sfx` 而不带着一片噪声。
   抢到粪球、扔出、赢了分别复用现成的 `catch` / `throw` / `win`。
2. **背景音乐**：`game/systems/bgm.gd`，132 BPM、两小节 8 拍、C-Am-F-G 的琶音 + 每两拍一个低音
   + 反拍沙锤，约 3.6 秒无缝循环。循环点落在乐句衰减完的地方，尾巴再补 40ms 线性收敛，
   所以接回去没有咔哒声（有测试盯着）。只在 `PoopGame` 处于这一局时 `start()`，收局 `stop()`。
3. **扔的动作**：`Player.throw_pulse()`（和 `chew()` 同一路数）。`Movement.throw_lean()`
   给一条「后仰 → 前甩 → 回正」的衰减正弦，0.35 秒，作用在 `_visual.rotation.x`。
   手上没球（客户端镜像的 `ammo` 为 0）不播动作和风声。
4. **飞出去的效果**：`PoopField` 里发的粑粑从「一颗球」变成「一个朝向飞行方向的节点 + 4 个
   越来越小的尾巴点」，本体每帧自转。方向直接用快照里的 `dx/dy/dz`（服务器已经在发）。
5. **被打中**：`PoopField` 盯 `hits[]` 的增量（纯函数 `hit_seats()`，可测），命中时
   ①那个人晃一下（`Player.hit()` / `RemotePlayer.hit()`，`Movement.hit_wobble()` +
   `hit_squash()`，0.45 秒）②帽子上弹出 3 块粑粑色块（`splat_spot()` 按 `cap_radius_at()` 摆，
   从 0 弹到 1，一局最多 9 块，收局一起清掉）③响「啪叽」。

## 留给实现的

色块的具体大小、尾巴点的间距、那一小段旋律好不好听 —— 这些按截图和真机听感调，
数字都放在 `Config` / `Movement` / `Bgm` 的 const 里。
